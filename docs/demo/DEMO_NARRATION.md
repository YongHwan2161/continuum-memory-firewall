# Demo narration

Continuum Memory Firewall prevents untrusted agent observations from becoming
durable authority. A model may propose, but CockroachDB decides what can be
committed.

This live build uses five-minute Cognito tokens, maps each verified caller to a
deterministic, row-level-security-confined database role, and embeds memory with
Amazon Titan. Our four-query evaluation achieved perfect Recall at three, with
zero cross-scope leakage.

The browser proof makes the boundary visible. High-similarity model output
without trusted provenance is rejected and quarantined. During failover, one
worker claims the action while the second returns duplicate, so authority has
one durable owner.

Similarity is not authority. Database presence is not provenance.
