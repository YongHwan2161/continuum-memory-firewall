## A failed action must not become memory

An agent can sound confident and still be wrong. The dangerous moment is not one failed action; it is when that failed outcome becomes trusted memory and silently changes every action that follows.

## Verified memory improves future action

On the one hundred forty-four future target episodes per arm, stateless succeeded 105 times, raw RAG 102, and Continuum 114. Continuum gained 8.33 percentage points over raw RAG in the paired comparison.

## Raw RAG remembers the wrong thing

The mechanism is visible, not inferred. Raw RAG canonically promoted 48 failed outcomes, then exposed unsafe memory 89 times and cited it in forty-three actions. Continuum never exposed an unsafe memory.

Continuum did not depend on a perfect model. It generated 38 unsafe proposals, but the verified outcome gate rejected them. Only successful provider receipts became canonical memory, producing 113 verified-memory-assisted successes with zero false promotions.
