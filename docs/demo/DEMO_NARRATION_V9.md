# Continuum Memory Firewall — live browser demo narration

Production agents need memory, but a failed action must never become the next agent's truth. Continuum is an outcome-gated memory firewall built with Amazon Bedrock and CockroachDB, and this is the live public judge console.

Here is a real browser action, not a mockup. I run one fixed, synthetic checkout incident. The deployed service retrieves with Titan, evaluates a poisoned instruction, and records the decision in the participant CockroachDB cluster.

The result is inspectable. Trusted memory is selected, poison is rejected, and exactly one action owner survives. This drawer exposes safe receipt prefixes, the Titan model, retrieval audit, caller binding, SQL role, and row-level security.

Now follow one provider outcome through the production memory path. A verified receipt becomes canonical CockroachDB memory, Titan retrieves it for the same cause, and a near-neighbor incident is rejected instead of inheriting the wrong action.

The paired episode explorer makes the causal contrast concrete. Raw RAG retrieves stale, poisoned, or conflicting memory and can propose the wrong action. Continuum accepts only server-issued citation handles backed by verified outcomes.

Provider truth is also replay-safe. Missing, forged, expired, cross-proposal, cross-provider, and receipt-mismatched authority all fail closed. CockroachDB records one outcome, one canonical promotion, exact replay, and an explicit conflict.

The authority chain is deliberately split. Bedrock proposes a bounded action; an independent provider verifier proves the effect; the server maps the caller to scope and SQL identity; CockroachDB RLS and vector search enforce the final memory boundary.

A judge can recompute the evidence without credentials. One click checks the static capsule, immutable release, exact workflow artifacts, database policy checksum, provider receipts, and public deployment. Every read-only gate must pass together.

That is Continuum Memory Firewall: the model proposes, the provider proves, and CockroachDB remembers only verified outcomes. The public demo, source, per-episode evidence, and one-click verifier remain available from this page.
