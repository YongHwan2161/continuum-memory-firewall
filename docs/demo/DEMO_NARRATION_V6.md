# Continuum Memory Firewall — real-provider demo narration

An agent failure is bad. Letting that failed action become the next agent's trusted memory is worse. Continuum Memory Firewall makes provider outcomes, not model confidence, decide what the system may remember.

We ran the same thirty-six paired incidents against real GitHub Releases draft effects. Six provider-state families cover create, update, inspect, and cleanup paths. Every action uses a parameter-free, action-specific schema, and every sandbox release remains a draft.

Amazon Bedrock proposes only a bounded action. The server owns the tenant scope and sandbox identity. GitHub returns the effect receipt. Only a verified receipt can cross the CockroachDB outcome gate and become canonical memory under row-level security.

Continuum completed thirty-six of thirty-six incidents. Raw RAG completed thirty-one. Continuum produced zero unsafe proposals, zero unsafe memory exposures, and zero false promotions. Raw RAG exposed unsafe memory twenty-three times and adopted it in five actions.

Those five paired wins are causal, not a synthetic score alone. Stale, poisoned, or conflicting history pushed raw RAG toward the wrong provider action. Continuum retrieved the same pressure but refused to promote an outcome until the provider receipt verified it.

The first live run also failed closed. GitHub's release list was briefly stale after creation, so reconciliation could not prove the effect. We deleted the exact residual draft, then changed the primary key to GitHub's server-issued release ID. The second run passed with zero residuals.

Release envelope v eleven binds that provider report to the exact source, workflow, artifact digest, CockroachDB policy checksum, AWS evidence, and two network-visible attestations. A retry adopted the immutable receipt without creating a second signature.

The public judge page performs read-only HTTP verification. It checks the thirty-six pairs, seventy-two observations, real-provider lineage, immutable assets, terminal coordinator receipt, vector evidence, RLS isolation, and the submitted Devpost record in one click.

Similarity can retrieve a memory, but only a verified outcome should earn trust. Continuum turns the provider receipt into the memory's causal identity, then makes that claim independently reproducible for judges.
